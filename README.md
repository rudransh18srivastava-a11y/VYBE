# VYBE Video Player

A responsive, browser-based video player for locally selected video files.

## Deploy with GitHub Pages

1. Create a GitHub repository (for example, `vybe-video-player`).
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your site will be available at:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Run locally

Open `index.html` in a modern browser.

## Privacy

Videos are selected and played locally in the browser. This app does not upload video files to a server.
